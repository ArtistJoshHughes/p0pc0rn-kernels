p0pc0rn kernels: benchmark

Runs the kernels at the sizes the p0pc0rn picture and clip models use. Benchmark times each new kernel next to the one it replaced (a few minutes). Tune for this device tries several settings of each kernel, checks each against the default's output, and finds the fastest here (5–15 minutes). Both warm the device up.
